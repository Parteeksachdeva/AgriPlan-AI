# AgriPlan AI

AgriPlan AI is an AI-driven agricultural decision-support system that helps farmers optimise crop selection through constrained optimisation and probabilistic profit modelling.

## Features
- Crop recommendation engine
- Monte Carlo profit simulation
- Risk-aware planning
- Acreage allocation optimisation
- What-if scenario analysis
